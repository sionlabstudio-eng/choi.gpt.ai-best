# Smart Habit Tracker

## 소개

Smart Habit Tracker는 사용자가 좋은 습관을 만들고 꾸준히 유지할 수 있도록 도와주는 습관 관리 서비스입니다.

매일 반복되는 목표를 기록하고 달성 현황을 시각적으로 확인할 수 있으며, 데이터를 기반으로 사용자의 행동 패턴을 분석하여 지속적인 성장을 지원합니다.

## 주요 기능

- 습관 생성 및 관리
- 일일 목표 달성 체크
- 연속 달성 기록(Streak) 제공
- 주간 · 월간 통계 확인
- 목표 달성 알림 기능
- 개인 맞춤 성장 리포트 제공
